MANUAL SETUP REQUIRED

1. Download the "GeoLite2 City" database (Binary, .mmdb) from MaxMind (free account required).
2. Rename the file to: GeoLite2-City.mmdb
3. Place it in this folder (public/data/).

The application will automatically load:
- base_logs.json (Sample Logs)
- malpedia.bib (Sample Threat Actors)
- GeoLite2-City.mmdb (Geolocation - if you add it)
